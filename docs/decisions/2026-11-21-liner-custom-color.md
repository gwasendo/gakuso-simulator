# ライナー・入子のカラー指定（v24.1）の方式

## 背景

油彩額の「ライナー・入子」は、金・銀の2種類の固定配色しか選べなかった。
実物のライナーは「白麻＋金」「グレー麻＋銀」のように、麻地と金属の組み合わせが多く、固定配色では再現できない。

要望は「デッサン・水彩額（マット・面金）側と同様の、実際の画像の取り込みとカラーピッカーを付けたい」というものだった。
調査の結果、**水彩側に画像の取り込みは存在しない**ことが分かった（存在するのはマット・面金のカラーピッカーのみ）。
要望の前提を確認したうえで、次の方式に決めた。

## 決定内容

| 項目 | 決定 |
|---|---|
| 画像の取り込みの目的 | **スポイト方式**。実物サンプル写真をタップして色を拾う。写真は描画しない |
| 色の指定方法 | **色選択UI（`<input type="color">`）とスポイトの両方**。写真がなくても色を選べる |
| 指定する部分 | **麻地の色と金属の色を別々に**指定する（入子は金属のみ） |
| 麻地の織り目 | 残す。糸の色を「地色＋一定のずれ」で作る（要件定義書§3.6-1） |
| 金属の配色 | 指定色から5段のグラデーションを規則で作る `deriveMetalStops()`（§3.6-2）。金・銀のプリセットは固定配色のまま |
| スポイトの拾い方 | タップ位置を中心とする 5×5 画素の平均、四捨五入。**1回のタップで1色**（§3.6-3） |
| 優先順位 | 後から操作した方が有効。種類選択カードを押すとカスタム色を両方解除し、v24.0.1 と同じ配色に戻る（§3.6-5） |
| 後方互換 | カラー指定を使わない既定状態で v24.0.1 と画素一致（§4.3・§7 T-11） |

### 麻地の糸のずれ

v24.0.1 の糸の色（地色 `rgb(209,197,184)`）から逆算した。明るい糸 ＋31、暗い糸 −39／−40／−39、交差点 −59／−59／−58。
既定の地色を与えると v24.0.1 の麻地タイルと画素一致することを試作で確認した。
地色の各チャンネルが 66〜217 の範囲なら、地色を変えた分だけ平均色が正確に動く（試作で誤差 0.25 以下）。
範囲外は糸の色が頭打ちになるが、ずれは縮めない（白麻でも暗い糸の陰で織り目が残るため）。

### 金属の係数

既存の銀の配色（中央 `#AAAAAA` に対する比 0.60／1.30／1.00／1.40／0.80）から逆算した。
影は掛け算（×0.6、×0.8）、光は白に寄せる計算（0.6、0.8）にした。`#AAAAAA` を指定すると既存の銀と完全一致する。

## 却下した案とその理由

| 案 | 却下の理由 |
|---|---|
| **写真をライナー・入子の模様として貼る**（コーナーサンプルと同じ方式） | 「ライナー用のコーナーサンプル」をもう1本持つのと同じ規模になる（帯の切り出し・四辺へのタイル貼り・45°の継ぎ・S倍の対応）。またライナーは幅が狭く、撮影した麻の織り目を縮小して貼ると潰れやすく、効果に比べて手間が大きい。**必要になれば v24.2 以降で再検討する** |
| **面金のカスタム色の係数（×0.5／×1.4）を流用する** | 両端とも0.5まで暗くするため、`#AAAAAA` を指定しても既存の銀（`#666666 #DDDDDD #AAAAAA #EEEEEE #888888`）を再現できない（`#555555 #EEEEEE #AAAAAA #EEEEEE #555555` になる）。また光を掛け算で作るため、明るい色が 255 で頭打ちになり色相がずれる |
| 麻地の地色が範囲外のとき、糸のずれを縮めて頭打ちを避ける | 白に近い色ではずれがほぼ0になり、織り目が消えてマットと見分けられなくなる |
| 麻地を単色で塗る | 仕上がりがマットと見分けにくくなる |

## 制約と今後の再検討

- **スポイトで拾う色は1回のタップで1色**。写真の色の分布（金箔のムラ、グラデーション、複数の色）は取り込まない。
  金属のムラや光り方は規則（§3.6-2）で作るため、実物の質感とは一致しない場合がある。**v24.2 で再検討する**
- **金属の明暗係数（×0.6／白寄せ0.6／白寄せ0.8／×0.8）は、実機確認の結果によって見直す可能性がある**。
  特に暗い色を指定すると光が強く出る（例: `#2B2B2B` → 光 `#D5D5D5`）ため、iPad 実機で違和感がないかを確認する
- スポイトで拾う色は撮影時の照明の影響を受ける。照明ムラ補正（処理A）はスポイト用の写真には適用しない
