# ライナー・入子カードの配色は実描画を正とする

## 背景

油彩額の「ライナー・入子の設定」欄には、種類を選ぶカードが4枚（ライナー金・ライナー銀・入子金・入子銀）あり、
それぞれに仕上がりの見本となる色帯が表示されている。

v24.0 時点で、このカードの配色と、プレビュー・エクスポートで実際に描かれる配色が一致していなかった。

| カード | カードの配色 | 実際の描画 | ずれ |
|---|---|---|---|
| ライナー：金 | 同じ5色・均等配置 | 同じ | なし |
| ライナー：銀 | `#888 #E8E8E8 #B0B0B0 #F0F0F0 #999` | `#666666 #DDDDDD #AAAAAA #EEEEEE #888888` | 5色とも違う |
| 入子：金 | 色は同じ。位置 0 / 30 / 50 / 70 / 100% | 位置 0 / 25 / 50 / 75 / 100%（均等） | 位置が違う |
| 入子：銀 | 色は同じ。位置 0 / 30 / 50 / 70 / 100% | 位置は均等 | 位置が違う |

原因は、同じ配色をカード用（canvas・CSS）と描画用で別々に直書きしていたこと（二重管理）。

v24.1 でライナー・入子のカラー指定を追加するにあたり、後方互換の基準（既定状態で v24.0 と画素一致）を先に確定させる必要があったため、v24.0.1 の修正として対応した。

## 決定内容

- **実際の描画の配色を正とし、カードをそれに合わせる**
- 配色を定数 `LINER_METAL_STOPS` の1か所にまとめ、カードと描画の両方がそこを参照する
- 入子カードは CSS グラデーションから canvas に置き換え、ライナーカードと同じ関数で描く
  （CSS に色を直書きしたままでは二重管理が残るため。また v24.1 でカードにカスタム色を反映するため）

## 却下した案とその理由

| 案 | 却下の理由 |
|---|---|
| 実際の描画をカードの配色に合わせる | プレビュー・エクスポートの画素が v24.0 から変わり、v24.1 の後方互換の基準（T-11）が動いてしまう。また v24.0 は実機確認済みの仕上がりであり、そちらを変える理由がない |
| CSS の数値だけ書き換えて揃える | 二重管理が残り、同じずれが再発する |

## 影響範囲

- プレビュー・エクスポートの画素: **変化なし**（描画側の値を変えていない）
- 見た目が変わる箇所: 「ライナー：銀」カードがやや暗くなる（実際の仕上がりに近づく）。入子カード2枚はグラデーションの位置がわずかに変わる
- 範囲外: 面金のカラーチップ（丸いアイコン）も CSS の配色が実際の描画と異なるが、45°方向の装飾的なアイコンであり仕上がりの見本ではないため、今回は対象外とした
